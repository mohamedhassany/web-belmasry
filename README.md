# Frontend Step — Mohamed Hassany

## توسيع الشرح والقراءة التفاعلية

النسخة دي مبنية على النسخة الأصلية من نفس المستودع، مع الحفاظ على الاسم والهوية والمسارات ومفاتيح التقدّم والتطبيقات.

- شرح تقني إضافي لكل موضوع داخل الدروس الـ45، مع توضيح طريقة التنفيذ والفروق والأخطاء الشائعة بدل التشبيهات اليومية.
- 45 تسلسلًا تعليميًا متحركًا، واحد لكل درس، بتكرار مستمر أثناء ظهوره على الشاشة. يمكن إيقاف كل الحركات أو تسلسل واحد والتنقل خطوة بخطوة. يحترم تفضيل تقليل الحركة، ويتوقف عند إخفاء التبويب أو فتح شرح مصطلح.
- قاموس مفصل يضم أكثر من 200 مصطلح. الألفاظ المعلّمة بنقط داخل الشرح تفتح نافذة فيها التعريف وآلية العمل والفروق ومواضع شرح مرتبطة. القاموس الكامل قابل للبحث.
- توضيح الأجزاء الأساسية للكود وقائمة مصطلحاته داخل جزء قابل للفتح تحت كل مثال مناسب، بدون تغيير النص الأصلي المنسوخ.
- عمود قراءة أهدأ ومسافات أكبر وضبط اتجاه النص اللاتيني وعزله داخل الفقرات العربية.
- الرسومات محاكاة تعليمية لخطوات الفكرة، وليست محررًا يشغّل كود الأمثلة.

ملفات الإضافة: `deep-content.js` و`deep-programming.js` للمحتوى، `learning-terms.js` للقاموس، `learning-motion.js` للرسومات، `learning.js` للتفاعل، و`learning.css` للقراءة والتجاوب. محملة من `dist/index.html`، ولا تحتاج خطوة build.

مدة الدرس لم تعد حدًا ثابتًا بساعتين؛ يمكن تقسيمه لجلسات حسب سرعة القراءة والتطبيق.

منصة تعليمية بالعامية المصرية، مكتوبة بـ HTML وCSS وJavaScript، وفيها أربعة مسارات:

- HTML: 6 دروس.
- CSS والتصميم المتجاوب: 8 دروس.
- JavaScript وDOM والشبكة والتخزين وOOP: 11 درسًا.
- React: 20 درسًا، من الأساسيات حتى الموضوعات العملية والمتقدمة ومشروع التخرج.

لكل درس صفحة شرح وصفحة مستقلة للأسئلة والتمارين والحلول. وقت الجلسة حسب سرعة الطالب؛ الدروس موسعة ويمكن تقسيمها على أكثر من جلسة قراءة وتجربة ومراجعة.

## التشغيل

افتح `dist/index.html` مباشرة، أو استخدم سيرفر محلي لتفعيل النسخ التلقائي وطلبات الشبكة بطريقة أفضل:

```powershell
node serve.mjs
```

افتح الرابط الذي يظهر في الطرفية. للإيقاف: Ctrl+C.

## الملفات

- `dist/index.html`: هيكل الموقع، الروابط والبيانات التعريفية.
- `dist/platform.css`: قواعد التخطيط الأساسية.
- `dist/calm.css`: التصميم الهادئ بالبنفسجي والأخضر الفاتح، عمود القراءة، والوضع الداكن والموبايل.
- `dist/lesson-visuals.js`: 73 رسمًا ومعاينة موزعة على كل الدروس، مكملة للمحتوى الأصلي.
- `dist/platform.js`: التنقل وعرض الصفحات والأسئلة والتمارين والتقدم المحلي.
- `dist/platform-data.js`: تقسيم الدروس، التوضيحات الإضافية، التصحيحات، والأسئلة والحلول.
- `dist/source-topics.js`: نصوص وأمثلة مستخرجة من ملفات الشرح الثمانية المقدمة. لا يشغّل scripts أو styles من الملفات المصدر.
- `dist/lessons.js`: شرح React ومساعدات بناء الأمثلة؛ التقسيم الظاهر للطالب وتخصيص مسار React موجودان في platform-data.js.
- `dist/assets/`: رسومات SVG محلية وأيقونة الموقع.

## التنقل

`#home` للرئيسية، و`#course/html` لدروس HTML، و`#course/html/practice` لتطبيقاتها. نموذج درس: `#learn/html/0` للشرح، و`#practice/html/0` لأسئلته. أسماء المسارات الأخرى: css وjs وreact. `#glossary` لقاموس المصطلحات. أرقام الدروس في الروابط تبدأ من صفر.

## المحتوى والمراجع

تم تنظيم محتوى HTML-All وCSS All وResponsive_Web_Design وJavaScript Basics وadvanced_js وJavascript_Math_Object وWhat-is-the-DOM-Anyway وOOP في دروس مرتبطة، مع توضيحات وتصحيح بعض التبسيطات غير الدقيقة وأمثلة أكثر أمانًا. ملفات المصدر الأصلية لم تتغير.

صفحات الأسئلة تضم 66 سؤال اختيار مع شرح الإجابة، وتمارين تطبيق لها حلول مخفية. علامات اكتمال الشرح وإجابات الأسئلة وقوائم المراجعة والوضع اللوني محفوظة في localStorage على الجهاز وأصل الموقع، وليس في حساب أو قاعدة بيانات. التمارين تُكتب في مشروع الطالب، والموقع لا يحتوي محرر أكواد أو تصحيحًا تلقائيًا للكود.

معاينات React داخل الشرح مكتوبة بـ JavaScript لتوضيح السلوك؛ الأمثلة المكتوبة بـ JSX تُجرّب في مشروع React/Vite منفصل. تجربة الشبكة تستخدم JSONPlaceholder وتحتاج إنترنت. الخطوط من Google Fonts لها بدائل محلية.

## استكمال React: الدروس 9–20

تمت إضافة 12 درسًا: Reducer وContext، Hooks والاشتراكات، Router، بيانات السيرفر وQuery، Forms وActions، الأداء وCompiler، الوصول وRefs وPortals، Suspense وحدود الأخطاء، TypeScript، الاختبارات، SSR وRSC، ومشروع تخرج ونشره. لكل درس 4 أسئلة وتطبيقان بحلول ورسم متحرك، مع مصطلحات قابلة للفتح.

ملفات الإضافة: react-advanced-core.js وreact-advanced-ui.js وreact-advanced-production.js وreact-advanced-terms.js وreact-advanced-motion.js. إجمالي الموقع 45 درسًا، و305 مصطلحات.

مشروع Study Board كامل في dist/react-capstone.zip ويمكن تنزيله من درس التخرج. يشمل المصدر وملف lock واختبارات Vitest؛ لا يحتوي node_modules أو أسرارًا. المهام محلية فقط وبيانات API تجريبية مستقلة. تم التحقق من الأنواع وبناء الإنتاج ونجاح 7 اختبارات، وتجربة التفاعل والمسارات والحفظ في متصفح فعلي.
